# Similarity method

Engine: `elimu-lexical` 1.0.0 (`server/src/engines/similarity.ts`). Every report records the engine name and version, the settings used, the scope of sources checked, and the hash of the exact version analysed.

## What it measures

The engine measures **exact and normalised word overlap** between a document and the sources in scope. It does not detect paraphrase, translation, idea-level reuse, or text generated by AI. The report says this in its Limitations section, and a similarity percentage is presented as evidence for human review, never as a finding of misconduct.

## Pipeline

1. **Normalise each word:**
   - Unicode NFKC;
   - lower-case;
   - strip diacritics;
   - unify typographic apostrophes and quotes.

   Character offsets into the original text are kept for highlighting.
2. **Fingerprint.** Every run of K = 5 consecutive tokens (a "shingle") is hashed with FNV-1a 64-bit. All positions are stored in `fingerprints`, so candidate retrieval is an indexed hash lookup and does not scan the whole corpus.
3. **Retrieve candidates.** Find the sources that share at least one shingle with the document, within the tenant-scoped corpus.
4. **Align.** For each candidate, extend shared shingles into maximal exact runs of tokens. Runs shorter than `min_match_words` (default 8, allowed range 5–50) are discarded.
5. **Eligibility.** Tokens inside excluded regions are removed from **both** the numerator and the denominator:
   - quotations (`"…"`, `“…”`), when `exclude_quotes` is on;
   - the bibliography (a heading such as References, Bibliography or Works Cited, and everything after it), when `exclude_bibliography` is on.
6. **Score.**

   ```
   similarity % = 100 × (eligible tokens covered by at least one counted run) ÷ (eligible tokens)
   ```

   - Each token counts **once**, however many sources match it.
   - In the per-source breakdown, a token is attributed to the source with the longest run covering it. Ties go to the lowest source id. Per-source figures therefore add up to the overall figure.
   - Percentages are rounded to one decimal place.
7. **Exclusions.**
   - **Automatic:** the assignment template, and the student's own earlier attempts unless `include_own_drafts` is set. These matches are stored and shown to reviewers, marked with the reason, but never counted.
   - **Reviewer:** excluding a source or a single match requires a written reason. It is stored with the reviewer and time, and can be reverted.
   - Exclusions remove tokens from the **numerator only**.
   - The report shows the *original* figure (before reviewer exclusions) next to the *adjusted* figure.

## Honest outcomes

| Situation | Status | What the user sees |
|---|---|---|
| No sources in scope | `no_sources` | "No sources were available to compare against. This is not a clean result." No percentage. |
| No eligible tokens (empty, all quoted, all bibliography) | `insufficient_text` | "Not enough eligible text." No percentage. |
| Sources checked, nothing matched | `completed` | 0%, with "No qualifying matches found in the checked sources." and "This does not guarantee originality." |
| Matches | `completed` | Percentage, highlighted passages, sources and excerpts (where the viewer is permitted to see them) |
| Scanned PDF | Import is held as `needs_ocr` | It is never analysed as an empty document |
| Swahili text | Matching runs (it is language-independent) | Notice: "not separately validated for Swahili" |

## Who sees what in a report

| Audience | Sees |
|---|---|
| Owner (personal) | Everything, including source excerpts |
| Staff of the assignment | Everything, including excerpts from other students' submissions in their assignment |
| Student | Only if the assignment enables `show_report_to_students`. Other students appear as "Another submission in this class", with no excerpt. Repository titles show as "restricted item". |
| Share link (external) | The report, without source excerpts from other students and with reviewer names replaced by "Reviewer" |

## Validation status

The engine is covered by unit tests: overlap is counted once, the minimum-length rule applies, quotation and bibliography exclusion work, numerator-only exclusions work, normalisation works, and the honest-outcome rules hold (`server/test/engines.test.ts`).

It has **not** been benchmarked against a labelled plagiarism corpus. Before institutional launch, a calibration study should do two things:
- choose `min_match_words` defaults per level (secondary school, undergraduate, postgraduate);
- measure false-positive rates on common academic phrases in English and Swahili.
